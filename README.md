## RFLauncher_Server

RF Launcher Server for the default playrf launcher.

## Main list of features

> Automatic PatchInfo.txt generation<br>
> Automatic Client patch .tmp packing<br>
> Automatic Whitelist-only access to gameserver and loginserver.<br>
> Forces players to connect using your Launcher, or they will not be whitelisted.<br>
> Temporary client patch download access, (you can't randomly GET request files).<br>
> Client patches cached and served from memory.<br>
> Many other features such as ratelimiting, windows firewall api com, persistent saved firewall state, stale rule/batched rule management, url pattern check, mimic cloudflare page to dissuade bots ect.
